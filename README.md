# SQL Cheat Sheets

Interactive, illustrated SQL cheat sheets: **https://sagarika-ramesh.github.io/sql-cheatsheets/**

Eight sheets on one mind map: SQL Basics, Joins, Aggregate Functions, Standard SQL Functions, Window Functions, SQL for Data Analysis, PostgreSQL, and SQL Interview.

- Every example states a task, shows the query, and shows the real result it returns.
- All results were produced by running each query in PostgreSQL 14 against one small sample dataset (an online bookshop), shown on the hub page.
- Each example has its own diagram, and each sheet has a mind map you can click to jump around.
- Search across all sheets, tick off what you know (saved in your browser), and flip the interview cards to test yourself.

Original examples and illustrations. Companion page: [SQL Gotchas, Illustrated](https://sagarika-ramesh.github.io/sql-gotchas/).
